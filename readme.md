## Website Project

DISD1 RAMS PLUMBING is a plumbing services website. The website
provides information about plumbing services and allows customers
to contact the company and request a quotation.

## Pages

The website contains five pages:

- Home
- About Us
- Services
- Gallery
- Contact

## Technologies Used

- HTML
- CSS
- Visual Studio Code
- Google Chrome
- GitHub

## CSS Styling

An external CSS file called `style.css` was created and linked
to all five HTML pages.

The website uses:

- Blue
- Light blue
- Orange
- White
- Dark grey

CSS Flexbox and CSS Grid were used to create the website layout.

## Responsive Design

The website was designed to work on:

- Desktop computers
- Tablets
- Mobile phones

Media queries were added to adjust the website for smaller screens.

The website was tested using Google Chrome Developer Tools.

## Testing

The following screen sizes were tested:

- Desktop: 1920 x 1080
- Tablet: 768 x 1024
- Mobile: 375 x 667

The navigation, images, services and contact form were checked
at different screen sizes.
